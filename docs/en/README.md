# Let's Learn Microsoft KARS

This eight-chapter course follows one continuous story: the Contoso Engineering
team turns Forge, an over-privileged coding prototype, into a governed software
development Agent. Each chapter introduces KARS through a product decision,
failure, or hands-on investigation.

## Contents

1. [The README That Changed the Architecture](01-why-kars.md)
2. [Reproducing Forge in a Safe Local Lab](02-local-quickstart.md)
3. [Turning a Demo into a Kubernetes Contract](03-kubernetes-api.md)
4. [Giving Forge Useful—but Bounded—Power](04-policies-and-tools.md)
5. [Moving Forge into a Governed Runtime](05-runtimes-and-byo.md)
6. [The Night Forge Kept Fixing the Same Test](06-security-and-operations.md)
7. [From One Sandbox to a Production Team](07-aks-and-multi-agent.md)
8. [Ship the Governed Development Agent](08-applied-project.md)

## Conventions

- Commands use a POSIX-compatible shell.
- Replace values in `<angle-brackets>`.
- Examples use the `kars-system` namespace.
- Local Kubernetes is the default learning environment.
- Production guidance assumes AKS.
